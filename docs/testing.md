# Duo Status V1 测试说明

## 1. 测试目标

测试重点不是覆盖所有 macOS 设备，而是确保 V1 在支持范围内：

- 状态读取结果可信。
- 组合图标、弹出面板和设置面板使用同一份状态。
- 状态暂不可用时不会显示误导性旧数据。
- CPU 和负载的图标变化经过平滑处理。
- 不支持的能力不会显示为可用按钮。
- V1 不触发任何非官方电源控制。

## 2. 测试层级

### 2.1 纯逻辑测试

不依赖真实 Mac 状态，覆盖：

- 电量百分比计算和 0% 至 100% 限制。
- 电池颜色优先级。
- Wi-Fi RSSI 到信号级别的映射。
- 网络类型对应的图标和是否显示 RSSI。
- CPU 健康分数。
- 系统负载健康分数。
- 热状态到健康分数的映射。
- 健康分数到 0 至 4 个点的四舍五入。
- 平滑处理。
- 无效值和暂不可用值。

健康分数边界处理和平滑算法尚未确认，相关测试应在对应决策完成后固定。

### 2.2 Provider 测试

Provider 应该通过协议或测试替身注入数据，不依赖测试机当时的真实电池和网络状态。

覆盖：

- BatteryProvider 能识别有内置电池和无内置电池。
- BatteryProvider 能识别电池、充电器和充电状态。
- NetworkProvider 能识别 Wi-Fi、有线网络、未连接。
- 无法确认热点时不会根据 SSID 名称猜测。
- Wi-Fi 名称或 RSSI 读取失败时只降级对应字段。
- HealthProvider 能处理 CPU、负载和热状态读取失败。
- 一个 Provider 失败不会阻断其他 Provider。

### 2.3 状态源测试

覆盖：

- SystemStatusStore 启动所有必要的刷新任务。
- 事件更新会更新统一快照。
- CPU 和负载按照固定周期刷新。
- 状态提交发生在 MainActor。
- 睡眠或读取失败时能标记数据不可用。
- 新快照会覆盖过期快照。
- 面板打开不会创建第二套轮询任务。

### 2.4 配置测试

覆盖：

- 健康指标可以保存和恢复。
- 开机启动选项可以保存和恢复。
- 图标外观可以保存和恢复。
- 默认折叠状态可以保存和恢复。
- 弹出面板修改健康指标后，设置面板读到相同值。
- 不保存 Wi-Fi 密码或管理员密码。

### 2.5 UI 测试

覆盖：

- 应用启动后显示菜单栏入口，不强制打开复杂主窗口。
- 点击菜单栏图标可以打开弹出面板。
- 上下文菜单可以打开设置和退出应用。
- 弹出面板包含 Battery、Network、System Health 区域。
- 三个区域可以折叠和展开。
- 设置面板包含 V1 已确认的四类设置。
- 状态摘要在菜单栏图标和弹出面板中保持一致。
- 不支持的写入能力不显示编辑控件。
- 简体中文和英文界面可以加载，其他语言回退英文。

## 3. 功能测试矩阵

### 3.1 电池

| 场景 | 预期 |
| --- | --- |
| 有内置电池、普通使用 | 显示电量弧线和普通单色 |
| 正在充电 | 电池进度颜色为绿色 |
| 低电量模式 | 电池进度颜色为黄色 |
| 未充电且电量低于 20% | 电池进度颜色为红色 |
| 无内置电池 | 显示中性不可用状态和无内置电池说明 |
| 电源信息暂不可用 | 不显示伪造的 100% 状态 |

### 3.2 网络

| 场景 | 预期 |
| --- | --- |
| Wi-Fi 已连接 | 显示 Wi-Fi、网络名称和可用信号级别 |
| 有线网络已连接 | 显示有线网络，不显示 Wi-Fi 信号强度 |
| 已确认个人热点 | 显示热点标签，不显示普通 Wi-Fi 信号强度 |
| 无法确认个人热点 | 显示普通 Wi-Fi，不根据 SSID 猜测 |
| 未连接 | 显示未连接，不显示网络名称和信号强度 |
| SSID 不可读 | 保留连接状态，SSID 显示暂不可用 |
| RSSI 不可读 | 保留连接状态和网络名称，信号显示暂不可用 |

V1 不测试 Wi-Fi 切换；该功能属于 V1.1。

### 3.3 系统健康

| 指标 | 预期 |
| --- | --- |
| CPU 使用率较低 | 健康点较多 |
| CPU 使用率较高 | 健康点较少 |
| 1 分钟负载较低 | 健康点较多 |
| 1 分钟负载较高 | 健康点较少 |
| Nominal | 健康分数 1.00 |
| Fair | 健康分数 0.67 |
| Serious | 健康分数 0.33 |
| Critical | 健康分数 0 |
| CPU 或负载短时抖动 | 图标不应明显闪烁 |
| 健康指标切换 | 菜单栏图标、弹出面板和设置面板同步 |

## 4. 兼容性矩阵

| 项目 | V1 要求 |
| --- | --- |
| macOS | 13 及更高版本 |
| 芯片 | 优先支持 Apple silicon |
| Intel | 不属于支持范围 |
| 网络 | Wi-Fi、有线网络、未连接；热点仅在系统确认时标记 |
| 权限 | V1 不申请管理员权限 |
| 数据来源 | 本机 Apple 公开 API |

兼容性验证需要完整 Xcode 和对应 SDK。当前工程已使用 Xcode 27 在 macOS destination 上通过应用构建和 `build-for-testing` 编译验证，单元测试也已在完整 Xcode 的 macOS destination 上执行通过。受限沙箱内直接连接 Xcode 的 `testmanagerd`/CoreSimulator 服务仍不可用；真实 Provider 仍需在 Apple silicon 设备上完成硬件状态验证。

## 5. 手动验收顺序

1. 在 Apple silicon Mac 上启动应用。
2. 确认应用只在菜单栏提供入口。
3. 打开弹出面板，检查三个状态区域。
4. 分别验证电池、Wi-Fi、有线网络和未连接状态。
5. 切换 CPU、温度和负载指标。
6. 观察 CPU 和负载短时变化，确认图标不会明显闪烁。
7. 修改四类 V1 设置，重启应用后确认设置保留。
8. 切换系统语言，确认简体中文、英文和英文回退。
9. 确认 V1 没有能源模式、充电上限或特权授权入口。

## 6. 验收限制

以下测试不能只依赖单台开发机：

- 无内置电池的 Mac。
- 有线网络。
- 个人热点身份被系统确认的场景。
- 各种系统热状态。
- 睡眠和唤醒。
- macOS 13 及更高版本之间的 API 差异。

无法复现的硬件状态必须通过 Provider 测试替身覆盖，不应为了测试而伪造系统级状态。

## 7. V1 之外的测试

### V1.1

- Wi-Fi 网络列表。
- 密码安全输入。
- 网络切换成功和失败。
- 切换后状态重新读取。
- 网络权限和系统设置回退入口。

### V2

- 能源模式能力检测。
- 充电上限能力检测。
- 用户主动授权流程。
- 辅助进程生命周期。
- 写入后重新读取确认。
- 后备实现失败后的官方只读回退。
