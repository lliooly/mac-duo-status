# Duo Status 产品规格

## 文档信息

- 产品名称：Duo Status
- 仓库名称：mac-duo-status
- 文档状态：基础状态版本与合并控制版本范围已确认
- 目标平台：macOS 13 及更高版本
- 首要支持架构：Apple silicon
- 首发语言：简体中文、英文
- 数据范围：当前 Mac 的本机状态
- 更新时间：2026-09-15

本文档是基础状态与合并控制版本的产品事实来源。它描述目标行为，不代表每个硬件场景都已完成实机验收。当前工程已接入真实系统状态采集、事件刷新、定时采样、开机启动和控制链路骨架。

## 1. 产品定位

Duo Status 是一个个人使用的轻量 macOS 菜单栏工具。它将电池、网络和系统健康状态聚合到一个组合图标中，让用户无需打开多个系统面板就能快速了解当前 Mac 的状态。

产品优先级如下：

1. 稳定读取本机状态。
2. 保持菜单栏图标轻量、清晰和低打扰。
3. 使用 Apple 公开 API。
4. 在不支持或无法读取时如实降级。
5. 将需要高权限或非官方实现的操作延后。

## 2. 范围与版本边界

### 2.1 基础状态版本包含

- 菜单栏常驻图标。
- 电池状态读取。
- 当前网络类型和连接状态读取。
- Wi-Fi 名称和信号信息读取（系统能够提供时）。
- CPU 使用率、系统负载和系统热状态读取。
- 组合图标的实时刷新。
- 点击图标打开弹出面板。
- 独立设置面板。
- 健康指标切换。
- 开机启动设置。
- 菜单栏图标外观设置。
- 弹出面板默认折叠状态设置。
- 简体中文和英文界面。
- 不支持状态和数据不可用状态的降级展示。

基础状态链路只负责只读快照；控制操作由独立控制层承接，不改变菜单栏图标和统一状态源的职责。

### 2.2 合并控制版本

合并控制版本同时包含 Wi-Fi 和电源控制能力，按设备能力、授权状态和后端可用性降级：

- Wi-Fi 扫描、系统已知网络展示、网络连接和 Wi-Fi 开关。
- 支持开放、WEP/dynamic WEP、WPA/WPA2/WPA3 personal、OWE 和 enterprise 安全族；不能映射的安全族明确失败。
- 密码、企业账号和身份引用只在当前操作期间存在，不持久化。隐藏网络需要用户明确输入 SSID。
- “记住此网络”允许用户选择，默认关闭；关闭时应用不主动提交配置文件，但不宣称覆盖 macOS 的全局记忆策略。
- 电源模式和充电上限先读取能力，再决定是否显示写入控件。
- 电源控制可通过签名的 LaunchDaemon/XPC 辅助进程承接；辅助进程未安装、待授权或后端不可用时保持只读。
- 所有写入均需经过 pending、后端执行、重新读取和 confirmed/writeUnconfirmed 状态确认。

Wi-Fi 和电源控制均不是基础状态 Provider 的隐式副作用；用户必须通过控制界面主动发起操作。

### 2.4 非目标

- 远程监控其他设备。
- 连接 iPhone。
- 读取蜂窝网络状态。
- 用户账号、云同步或服务器。
- 进程级 CPU 排名。
- 复杂历史图表和日志系统。
- 默认使用私有 API。
- 让主应用整体以 root 身份运行。
- 支持 Intel Mac。

## 3. 支持范围和语言

### 3.1 系统和硬件

- 支持 macOS 13 及更高版本。
- V1 优先支持 Apple silicon。
- Intel Mac 不属于 V1 支持范围，不承诺功能或性能兼容性。

工程文件已经将部署目标调整为 macOS 13.0。后续仍需在完整 Xcode 环境中验证各平台 API 的可用性。

### 3.2 语言

- 系统语言为简体中文时使用简体中文。
- 系统语言为英文时使用英文。
- 其他语言回退英文。
- 技术名词保留行业通用英文，例如 MenuBarExtra、CoreWLAN、RSSI、CPU 和 API。

## 4. 界面职责

### 4.1 菜单栏图标

菜单栏图标只负责摘要和入口：

- 固定展示电池、网络和系统健康三部分。
- 不显示电池百分比数字。
- 实时反映统一状态源提供的最新快照。
- 左键或主点击打开弹出面板。
- 菜单栏上下文菜单提供打开设置和退出应用入口。
- 数据不可用时显示中性或降级状态。

电池和网络部分不提供隐藏开关。只有下方四个健康点的指标含义可以切换。

### 4.2 弹出面板

弹出面板负责查看当前状态：

- 顶部显示较大的组合图标。
- 显示设备名称或简短标题。
- 显示最近一次状态更新时间。
- 显示状态暂不可用时的简短说明。
- 使用 Battery、Network 和 System Health 三个可折叠区域。
- 允许切换健康指标，并立即同步到设置。
- 在面板底部提供“打开设置”入口，点击后打开独立设置面板。
- 根据能力状态显示 Wi-Fi 和电源控制入口；不支持、待授权或暂不可用时显示只读说明和回退入口。
- 控制操作显示独立的进行中、成功、失败或未确认状态，不把本地选择直接当成系统已生效。

### 4.3 设置面板

V1 设置面板包含：

- 开机启动。
- 菜单栏图标外观。
- 下方四个点的默认指标。
- 弹出面板各折叠区域的默认状态。

设置面板和弹出面板必须读写同一个配置源。设置页不复制所有即时状态，只提供长期配置和状态入口。

设计稿中关于「点击外部区域后关闭弹出面板」是否作为可配置项，本轮尚未单独确认；V1 不为该项规定额外行为。

## 5. 组合图标

组合图标固定包含三部分：

1. 上半圆：电池电量。
2. 中间区域：网络状态。
3. 下方四个点：系统健康状态。

图标表达趋势，不承担详细数据展示。详细数字和说明放在弹出面板中。

### 5.1 电池区域

电池区域由两层组成：

- 底层是代表 100% 的完整上半圆轨道。
- 上层根据当前电量绘制实际进度。

电量按当前容量除以最大容量计算，并限制在 0% 至 100%。

颜色优先级：

1. 由电源适配器供电：绿色。
2. 低电量模式：黄色。
3. 未由适配器供电且电量低于 20%：红色。
4. 普通使用电池：使用适配浅色和深色菜单栏的单色。

没有内置电池的设备不把外接电源显示成电池 100%。电池区域显示中性不可用状态，面板显示「无内置电池」。

### 5.2 网络区域

网络区域表达当前主连接：

- Wi-Fi：使用 Wi-Fi 图形，并根据 RSSI 显示信号级别。
- 有线网络：使用有线或网络类图标，不显示 Wi-Fi 信号强度。
- 个人热点：只有系统能够确认时才显示热点标签，不根据 SSID 名称猜测。
- 无法确认热点身份时显示普通 Wi-Fi。
- 未连接：显示断开或不可用状态。

连接类型和连接状态优先使用 NWPathMonitor 判断，Wi-Fi 名称和 RSSI 使用 CoreWLAN 补充。

### 5.3 健康区域

下方四个点表示当前健康分数：

- 点越满：CPU 使用率越低、系统负载越低或温度状态越好。
- 点越空：CPU 使用率越高、系统负载越高或温度状态越差。

健康指标固定支持：

- CPU 使用率。
- 系统热状态。
- 系统负载。

V1 不开放用户自定义阈值。

## 6. 健康分数

### 6.1 CPU

CPU 健康分数为：

    1 - CPU 使用率 / 100

CPU 使用率使用平滑后的采样值参与图标映射，避免图标闪烁。

### 6.2 系统负载

系统负载健康分数为：

    1 - 1 分钟负载 / 逻辑 CPU 数

系统负载使用平滑后的采样值参与图标映射，避免图标闪烁。

### 6.3 热状态

| 热状态 | 健康分数 |
| --- | ---: |
| Nominal | 1.00 |
| Fair | 0.67 |
| Serious | 0.33 |
| Critical | 0 |

### 6.4 四点映射

四个点数量为：

    健康分数 × 4 后四舍五入

健康分数的边界处理和平滑窗口尚未在产品层面进一步指定，见「待确认事项」。

## 7. 详细面板内容

### 7.1 Battery

面板可展示：

- 当前电量。
- Power Source：Battery 或 Power Adapter。
- 是否由电源适配器供电（界面字段名为 Charging）。
- 低电量模式状态。
- 无内置电池说明。
- 打开系统电池设置的入口（具体是否作为 V1 必备入口，尚未单独确认）。

能源模式和 Maximum Charge 是否显示写入控件由电源能力与辅助进程状态决定；能力不足时只显示读取结果或授权说明。

### 7.2 Network

面板可展示：

- 当前连接类型。
- 当前网络名称。
- 连接状态。
- Wi-Fi 信号级别。
- Wi-Fi 名称或 RSSI 暂不可用的说明。
- 打开系统网络设置的入口。

网络控制使用独立的网络选择页，不直接把下拉选择写入系统。个人热点只有在系统能够确认时才标记为热点。

### 7.3 System Health

面板可展示：

- CPU、温度和负载三个指标选项。
- 当前选中指标的详细数值。
- 四点健康摘要。
- 当前状态说明。
- 负载的 1 分钟值；是否同时展示 5 分钟和 15 分钟值，沿用实现阶段的界面容量判断。

V1 不加入复杂历史曲线。

## 8. 数据刷新和一致性

### 8.1 事件驱动

- 电池：监听 IOPowerSources 电源变化。
- 网络：监听 NWPathMonitor 路径变化；使用 CoreWLAN 补充 Wi-Fi 信息变化。
- 热状态：监听 ProcessInfo 的 thermalStateDidChangeNotification。
- 低电量模式：监听 NSProcessInfoPowerStateDidChange。

### 8.2 定时采样

CPU 使用率和系统负载是连续变化的统计值，需要周期采样。设计稿建议约 2 s 更新一次，并要求对 CPU 和负载做平滑处理。

V1 不提供过高频率的刷新设置。菜单栏图标关闭弹出面板时仍保持刷新；系统睡眠或无法提供数据时可以暂停，唤醒后重新读取完整快照。

### 8.3 一致性

- Provider 在后台采集数据。
- 统一状态更新在主线程或 MainActor 上提交。
- 菜单栏图标、弹出面板和设置面板订阅同一份状态快照。
- Provider 失败时清除或标记过期数据，不把旧数据伪装成当前数据。
- 面板打开时读取当前快照，不创建第二套轮询机制。

## 9. 降级和错误处理

### 无内置电池

显示无内置电池，电池图标使用中性状态；网络和健康功能继续工作。

### 无网络连接

显示未连接，不显示网络名称和信号强度；保留打开网络设置入口。

### Wi-Fi 信息不可读

仍显示 NWPathMonitor 能确认的连接状态。SSID 和 RSSI 显示暂不可用，不影响其他状态。

### CPU 或负载读取失败

下方四个点显示中性不可用状态，健康面板显示暂不可用；电池和网络继续工作。

控制写入失败时必须回退到官方只读状态，不把失败操作显示为成功，也不自动重复重试高风险写入。电源辅助进程不可用属于可预期的能力降级，不应阻断应用启动。

## 10. 数据源和安全边界

基础状态优先使用 Apple 公开 API；控制层使用明确隔离的本机适配：

- IOPowerSources：读取电池基础信息。
- NWPathMonitor 和 NWPath：读取连接类型和连接状态。
- CoreWLAN：读取 Wi-Fi 名称和 RSSI。
- CoreWLAN：扫描、连接和切换 Wi-Fi。
- SMAppService、LaunchDaemon 和 XPC：承接可选的电源辅助进程。
- ProcessInfo：读取热状态和低电量模式。
- 公共 Mach 接口：读取 CPU 统计。
- getloadavg：读取系统负载。

系统不接入管理员密码采集、任意 shell 命令拼接或主应用 root 运行。Wi-Fi 密码不持久化；电源辅助进程只暴露固定方法，并在签名和授权不满足时降级为只读。

## 11. V1 设置

### 开机启动

用户可以开启或关闭开机启动。具体使用的系统登录项 API 在架构实现阶段确定。

### 图标外观

用户可以配置菜单栏图标是否使用颜色。菜单栏图标默认使用适配浅色和深色菜单栏的单色；弹出面板可以使用语义颜色表达严重和临界状态。

### 默认折叠状态

用户可以配置 Battery、Network 和 System Health 区域的默认展开状态。

### 健康指标

用户可以选择 CPU、温度或负载作为下方四个点的默认指标。弹出面板中的即时切换立即同步到设置。

## 12. 验收标准

- 应用启动后只在菜单栏显示图标，不强制打开复杂窗口。
- 电池、网络和健康状态均来自本机。
- 电池弧线能表达 0% 至 100% 的连续变化。
- 充电、低电量模式和低于 20% 的颜色逻辑正确。
- Wi-Fi 信号按级别显示。
- 有线网络和个人热点不显示普通 Wi-Fi 信号强度。
- 无法确认个人热点时显示普通 Wi-Fi，不根据 SSID 猜测。
- 下方四个点可以切换 CPU、温度和负载三种含义。
- 低负载、低使用率和低温对应更多点；高负载、高使用率和高温对应更少点。
- 电池、网络和系统健康信息分别位于可折叠区域。
- 设置面板可以修改健康指标并持久化。
- 设置面板可以修改开机启动、图标外观和默认折叠状态。
- 顶栏图标、弹出面板和设置面板状态一致。
- Wi-Fi 控制页允许用户选择网络；“记住此网络”默认关闭且不会保存密码。
- Wi-Fi 写入成功必须通过连接状态和 SSID 读回确认；失败时保留真实当前状态。
- 不支持、待授权或未确认的功能不显示为可用写入控件。
- CPU 和负载按照约定周期刷新，并使用平滑值避免图标闪烁。
- 不要求 Intel Mac 兼容。
- 电源辅助进程不可用时仍显示公开只读状态，不伪造能源模式或充电上限写入结果。

## 13. 待确认事项

以下内容在现有讨论中没有足够细节，本规格不替用户做决定：

1. 系统负载健康分数超过 1 或小于 0 时，是否统一限制到 0 至 1。
2. CPU 和负载平滑算法、采样窗口和具体采样间隔。
3. 电源写入后端在各机型上的正式支持矩阵和签名发布流程。
4. Intel Mac 启动后的具体表现。
5. Battery 面板中打开系统设置入口是否属于 V1 必备验收项。
6. 弹出面板「点击外部区域后关闭」是否需要成为可配置项。

## 14. 后续路线

### 合并控制版本：持续验收

持续验证 CoreWLAN 的切换能力、权限、失败原因、密码输入和“记住此网络”流程；同时评估能源模式、充电上限和辅助进程后端在不同机型上的兼容性、签名、授权和安全边界。只有在能够保持主应用稳定并完成读回确认时，才开放对应写入能力。
